# 📝 ACK Note List

A simple and responsive To-Do / Note List web application built with Python Flask and SQLite.

## 🚀 Live Demo

👉 [Open ACK Note List](https://ack-note-list.onrender.com)

## 📂 GitHub Repository

👉 [View Source Code](https://github.com/allamsetty-chaitanyakumar/todo_app)

## ✨ Features

- ➕ Add notes
- ✏️ Edit notes
- ✅ Mark notes as completed
- 🔄 Mark notes as incomplete
- 🗑️ Delete notes
- 💾 SQLite database
- 🌐 Live deployment on Render

## 🛠️ Technologies

- Python
- Flask
- SQLite
- HTML
- CSS

## 🚀 Run Locally

```bash
git clone https://github.com/allamsetty-chaitanyakumar/todo_app.git
cd todo_app
pip install -r requirements.txt
python app.py
